# SPR-IoT reproducibility artifact

Static MQTT policy repair under explicit topic-language and deployment constraints. SPR is the checking/repair/export/validation system; direct exact E is its standard backend. Q is an optional contextual quotient, not a demonstrated acceleration.

## Paper and evidence

- `SPR_IoT.pdf` / `SPR_IoT.tex`: current eight-page manuscript, 36 references.
- `results/gn1_comparison_20261118_v2/`: frozen 144-run follow-up, all 36 existing pressure specifications x G/G_N1/E/Q, cap 3, 5 seconds/process, one seeded randomized order.
- Follow-up completion: G 30/36; G_N1, E and Q 34/36. All four recovered tasks belong to redundant Allow. G_N1's 34 common returns have the same measured edit cost as E/Q, without a general optimality claim. G_N1 has two stalls; E/Q each have two timeouts.
- `results/gn1_comparison_20261118/`: preserved first attempt with a progress-recorder error (28 E/Q implementation errors). It is not an algorithm comparison. The recorder was fixed and all 144 slots rerun; no failed slot was silently replaced. Both code snapshots are retained.
- `results/round4/offline_v2/`, `grid/`, `broker/` and `results/body_results/`: historical controlled raw records/derived tables. Historical E/Q 34/36 includes one infeasible case and one timeout, distinct from the follow-up's two timeouts.
- Historical Broker counts: 127 probes, 80 controls, 300 nested latency observations; 15 complete offline timing pairs and 10 Broker pairs. Separate small boundary regression: 32 probes, four controls and six identity-denial checks. These populations are never added together.

Run commands and exact coverage are in [REPRODUCE.md](REPRODUCE.md). Licenses/exclusions are in [NOTICES.md](NOTICES.md). The archive and Git tree use the same files; `SHA256.json` and `SOURCE_HASHES.json` record hashes and any path-only privacy redactions.

The four controlled templates and fifteen initial semantic classes do not establish independent real-error generalization. The follow-up has one timing observation per method/task, not a speed-significance experiment. Q has no observed candidate reduction/stable speed benefit. Fixed subscriptions, printable ASCII, one role and a static snapshot delimit the model. The new batch's hardware metadata is not backfilled into historical measurements.
