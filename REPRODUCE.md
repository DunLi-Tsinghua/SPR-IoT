# Reproduction commands and scope

Use Python 3.14 and TeX Live. Commands below run from this extracted artifact/repository root. Paper/figures/results are a frozen publication snapshot; use clean output paths.

1. `build.cmd`: compile SPR_IoT.tex into SPR_IoT.pdf (8 pages including references). Class, fonts, margins and figure sizes are unchanged; current text/float gaps are 10pt plus/minus 2pt.
2. `python scripts/verify_public_release.py`: verify packaged SHA-256 hashes, counts and exclusions. Run before rebuilding outputs, since a new PDF timestamp changes its hash.
3. `python -m unittest discover -s tests`: run included tests. The full local project passed 58 tests; the two test modules requiring excluded upstream public-policy task data are omitted here. The actual included-test count is recorded in results/release_validation.json after clean extraction.
4. `python scripts/summarize_gn1_comparison.py`: recompute summaries and finite independent checks from the recorded follow-up, not a new experiment.
5. `python scripts/run_gn1_comparison.py run --out results/reproduce_gn1`: run a fresh 144-process comparison on the existing 36 inputs. Refuses an existing output path; code/tasks/order are frozen first. Each process has 5s including imports, generation, search, audit and output. Worst child budget 720s plus cleanup, 20MiB initial disk envelope. No automatic tuning/retry or historical overwrite. Then `python scripts/summarize_gn1_comparison.py --out results/reproduce_gn1`. Statuses can differ across hardware/load; do not demand a favorable fixed count or pool timings with the published batch.
6. With numpy/matplotlib, `python scripts/plot_redesign_20261103.py --output figures/replot_check`: regenerate the three historical numerical figures from packaged CSV. No solver/Broker invocation. Existing graph PDFs are supplied; regenerated PDF metadata may differ. Editable draw.io sources and the official-Desktop export script are also included (install matching draw.io separately).
7. To replay Broker paths, place official Mosquitto 2.1.2 binaries/tools and matching plugin in tools/broker/2.1.2/. Binary/plugin hashes are in the environment/source records. `python scripts/check_deployment_boundary_20261118.py --out results/reproduce_boundary` runs the separate small regression on port 28902. `python scripts/broker_round4.py --phase E5 --out results/reproduce_broker` and then phase E6 replay the recorded deployment schedule from frozen policies; they do not rerun repair. Ports must be free; only loopback and newly created Broker processes are used. No original experiment is silently rerun by build/replot/summary commands.

All historical controlled inputs/raw records needed for the supplied figures and frozen Broker policy references are included. Full historical offline orchestration and licensed public-policy acquisition are not claimed as a one-command reproduction here. Failed, stalled, timeout and unavailable records remain. Real message receipts are nested within runs, not independent task repetitions.
